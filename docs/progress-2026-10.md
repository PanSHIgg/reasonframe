# ReasonFrame（理象）开发进度

更新日期：2026-10-21。

目前已实现从题目输入到 MP4 下载的后台服务，并完成一条高三数列题的真实端到端试跑。该样片经过多轮返修才完成，当前仍处于验证工作流、积累题型与改进质量检查的阶段。

## 已完成的开发

### 1. 后台服务与任务管理

- 使用 Node.js 24、TypeScript 和 Express 构建 HTTP 服务，不做网页工作台。
- 输入支持题目文字、图片、学科、年级、知识范围、允许或禁止的方法以及补充要求。
- 实现持久化任务队列、阶段状态、SSE 事件、取消、失败重试和产物下载。
- 提供 OpenAPI、健康检查、脱敏配置查询及可选服务 API Key。
- 任务源码、讲稿、音频、字幕、时间线和检查报告保存在独立工作区。

### 2. Pi Agent 与模型接入

- 引入 `@mariozechner/pi-coding-agent` SDK，由 Agent 编辑 `lesson.json`、`src/visual.js` 和 `src/style.css`。
- 支持 OpenAI Responses、OpenAI Chat Completions、Anthropic Messages 三种端点；通过 `.env` 或配置文件选择协议、URL、API Key 和模型。
- 接入模型上下文、最大输出、请求超时、重试、退避、思考等级、温度，以及 Agent 总超时、轮数、工具调用和返修预算。
- 当前真实联调使用 OpenCode 的 `minimax-m3.1-flash-free`，Chat Completions 协议；本地配置为上下文 1,000,000、最大输出 524,288、思考等级 `xhigh`。
- 作者与独立审核使用不同会话。作者工具限制在任务文件内，不能运行任意 shell 或修改服务端检查报告。
- 提示词已从代码拆到 `prompts/base/{author,reviewer}.md` 与 `prompts/subjects/{math,physics,chemistry}.md`；服务按 `scope.subject` 组合，审核报告绑定审核提示词摘要，改提示词后旧批准失效。

### 3. 讲稿编辑与自动返修

- 增加 `read_lesson`、`write_lesson`、`update_lesson`，避免直接编辑 JSON 引发多层转义和类型错误。
- 批量更新使用 JSON Pointer 和明确的字符串、数字、布尔、数组或 JSON 参数，先校验整批内容再原子保存。
- 文件列表仅返回实际存在的文件；缺失文件有明确的新建提示。
- 增加 `validate_preview`：已有完整音频时，可重新编译并刷新真实浏览器及 HyperFrames 检查，供作者和审核者完成返修。
- 稿件通过独立审核后绑定源码摘要；后续源码变化会使审核失效。

### 4. 画面、字幕与高亮

- 编译生成 HyperFrames 项目，支持纯黑背景、分步公式、对象高亮、逐词字幕及按时间定位画面。
- 提供立体几何起始模板和通用模板；数列样例另外实现点图、求导对应关系、错位相减的整行移动与逐列高亮。
- 用同一份词时间表驱动字幕、场景和高亮提示。
- 增加准确的 `beatStarts`，修复后续高亮提示导致动画回跳的问题，并验证反向 seek 的确定性。
- 修复片头父容器淡入导致第 0 帧标题不可见的问题。

### 5. 全文免费 TTS

- 实现直接 Edge TTS CLI 适配器，默认使用 `zh-CN-XiaoxiaoNeural`、正常语速；每次完整讲稿启动一个 Python 进程，不依赖常驻服务。
- 每版讲稿通过一条完整 SSML 请求合成，返回完整 MP3 和原生词级时间表，不拆句拼接、不按字数估算时间。
- 修复 SDK 默认 4096 字节分块限制；对含请求头的完整消息设置 60,000 字节上限，超限时在请求前明确拒绝。
- 按讲稿、声音及相关版本信息缓存结果；讲稿不变时复用完整音频，讲稿改变后重新整篇合成。
- 同时保留外部 MP3 与词表导入接口，便于后续更换 TTS API。

### 6. 质量检查与成片复用

- 检查讲稿结构、公式渲染、数值断言，并进行独立模型审核。
- 审核拆成 `textClean`、`reasoningClear`、`layoutClean` 等内容门；审核顺序固定为“逐字文字校对 -> 逻辑/解题 -> 易懂性 -> 图形版式”，旧审核报告缺少新门会被判失效。
- 作者和审核提示词采用 Polya 四步和 worked example 结构：先理解题意，再说明方法及适用条件，逐步给依据，最后回看；选择题必须逐项判断，最终答案只在汇总出现。
- 检查全文词表覆盖、时间顺序、字幕对齐、高亮对象存在及可见性、画面越界与字幕区侵入。
- 执行真实浏览器和 HyperFrames 的布局、运行时、动画及过渡检查。
- 对 MP4 检查音视频轨、分辨率、帧率、时长、帧数、全量解码、异常黑帧、静音和音量。
- 用 HyperFrames 原生快照与编码帧比较，保留 SSIM ≥ 0.97 的门槛；原浏览器截图继续用于语义和布局检查。
- 对源码、时间线、编译产物、校验器和视频进行摘要绑定，允许失败重试复用已经验证的完整 MP4。

## 已完成的真实样片

题目输入位于 [examples/sequence-derivative/request.json](../ai-service/examples/sequence-derivative/request.json)，原图位于 [examples/sequence-derivative/problem.png](../ai-service/examples/sequence-derivative/problem.png)。

题设为 `a₁ = 3`、`aₙ₊₁/n = aₙ/(n+1) + 1/[n(n+1)]`，要求证明 `{n aₙ}` 为等差数列，并对 `f(x) = Σ aₖxᵏ` 求 `f′(-2)`。

讲解得到 `n aₙ = n + 2`、`aₙ = 1 + 2/n`，最终答案为：

```text
f′(-2) = [7 - (3m + 7)(-2)^m] / 9
```

该结果另经 SymPy 符号求和与 30 组精确有理数检验；服务内最终稿包含 31 项数值检查。

## 试跑中发现并修复的问题

- 数值模型正确但画面公式错误：修正显示文本、口播和图形示例，强化独立审核，不能只看数值断言。
- LaTeX 多层转义、JSON 类型丢失与局部修改失败：改为结构化讲稿编辑和明确类型的工具参数。
- 审核要求新预览，但作者无法刷新：补充真实预览工具，接通返修闭环。
- 动画随高亮提示重新计时：改用稳定的 beat 起点。
- 全文配音被 SDK 隐式分块：改为完整 SSML 请求并增加请求前长度校验。
- 浏览器预览与 HyperFrames 编码的捕获路径不同：改用原生快照作为编码比较基准，未降低一致性门槛。
- 一次维护重启误中断了已经开始的渲染：后续重启前检查活动任务，最终完整渲染和交付已完成。
